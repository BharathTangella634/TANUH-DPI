Head CT Report Checker Documentation

TANUH-CBR IndiNeuroFM Head CT Report Checker

1. Overview

The Head CT Report Checker is an automated CT report verification framework that assesses consistency between Head CT scans and their corresponding radiology reports. The service is designed to verify whether findings mentioned in a report are supported by the imaging evidence and to generate binary review tags: PASS or Needs Review.

Radiology interpretation errors and discrepancies are a known clinical quality challenge. Caranci et al. describe daily-practice radiologic interpretation errors around 4%, with report discrepancy ranges that can vary by setting and review context (PubMed PMID: 26183038). At global imaging volumes, even a small error rate can translate into a large number of interpretive errors each year, especially in abnormal or emergency-after-hours studies.

The objective of this work package is to build an inference-only pipeline that combines multiple pretrained medical foundation models. Rather than training new models, the framework uses an ensemble strategy to integrate complementary model capabilities for CT image understanding and report verification.

2. Key Features

  • Verifies consistency between a Head CT scan and its matching radiology report
  • Uses de-identified clinical CT datasets and associated reports from clinical partners
  • Works with CT images in NIfTI format and report PDFs
  • Evaluates a selected pool of five recent and efficient medical foundation models
  • Combines outputs from two to three selected models using an ensemble, mixture-of-experts strategy
  • Generates structured finding-level decisions with PASS and Needs Review tags
  • Provides confidence scores and explanatory reasoning to support clinical quality assurance
  • Creates standardised model cards covering model capabilities, input requirements, limitations, and deployment characteristics

3. Architecture

The framework follows a modular inference pipeline for scan-report verification. A paired Head CT scan and report are prepared, processed through a unified preprocessing layer, evaluated by a selected ensemble of medical foundation models, and converted into a consensus verification output.

  1. Input: CT image in NIfTI format and corresponding report PDF
  2. Preprocessing: standardise CT volume inputs so selected models can process clinical partner data
  3. Model inference: run multiple pretrained medical foundation models on the Head CT scan and report context
  4. Finding comparison: compare model-generated imaging observations with the corresponding report findings
  5. Consensus generation: combine model outputs to improve robustness and reliability
  6. Verification output: produce a PASS or REVIEW flag with finding-level tags, confidence scores, and explanatory reasoning

4. Usage Guide

The intended workflow is:

  1. Upload one Head CT scan in NIfTI format
  2. Upload the corresponding radiology report PDF
  3. Submit the paired case for automated verification
  4. Review finding-level outputs tagged as PASS or Needs Review
  5. Use the generated PASS or REVIEW flag, confidence scores, and explanation to assist radiologist review

5. Privacy & Security

The planned workflow uses de-identified CT datasets and reports obtained through clinical partners. The service is intended to support clinical quality assurance while protecting patient privacy, with secure handling of imaging volumes and report documents throughout the review process.
